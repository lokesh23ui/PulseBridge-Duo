# PulseBridge Duo — Simulation Resources

This directory contains standalone simulation data payloads, test fixtures, and scripts for driving the PulseBridge Duo platform.

## Directory Structure
- `sample-data/`: Contains canonical JSON payloads for testing backend ingestion and frontend simulation.
  - `wokwi_sample.json`: The exact canonical Phase 1 Wokwi ESP32 payload.
  - `ring_sample.json`: High-frequency simulated ring telemetry sample.
  - `watch_sample.json`: High-frequency simulated smartwatch telemetry sample.
  - `dual_sample.json`: Coordinated dual-wearable correlation sample.
